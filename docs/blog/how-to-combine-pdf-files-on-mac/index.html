How to Combine PDF Files on a Mac (3 Free Ways)

Published 2026-10-24

Macs come with everything you need to combine PDF files, no paid software required. There are three good ways to do it, and which one is best depends on whether you want speed, control over individual pages, or a method that works the same on any computer.

Method 1: Finder Quick Actions (fastest)

Since macOS Mojave, Finder can turn several files into one PDF in two clicks:

  1. Put the PDFs in the same Finder window.
  2. Select them: click the first, then hold Command and click the others.
  3. Control-click (or right-click) one of the selected files and choose Quick Actions → Create PDF.

A new PDF appears in the same folder, usually named after the first file. Finder combines the files in the order they are listed in the window, so the easiest way to control the order is to rename them with numbers first, such as 1-cover.pdf, 2-letter.pdf, 3-references.pdf, and sort by name. Quick Actions also accepts images, so you can mix photos and PDFs in one go.

Method 2: Preview (best for choosing pages)

Preview, the Mac’s built-in PDF viewer, lets you see every page as you assemble the document:

  1. Open the first PDF in Preview.
  2. Choose View → Thumbnails so page thumbnails show in the sidebar.
  3. Drag another PDF from Finder into the sidebar. Drop it between the thumbnails where you want its pages to go. A line shows where they will land.
  4. Repeat for any other files, and drag individual thumbnails up or down to reorder pages.
  5. Choose File → Export as PDF and save under a new name.

You can also add a whole file with Edit → Insert → Page from File. To remove a page, select its thumbnail and press Delete. Exporting to a new name keeps your original files unchanged, which is safer than saving over them.

One common snag: if you drag a file onto a thumbnail rather than between thumbnails, Preview may annotate the page instead of inserting new pages. If that happens, press Command-Z and drop the file in the gap between two pages.

Method 3: A browser tool (works on any Mac, iPad or PC)

If you prefer a simple list where you can reorder whole files with buttons, use Merge PDF in Safari or Chrome. Choose the files, arrange them, click Merge and download. The PDFs are combined inside your browser and are not uploaded, so it is fine for personal documents. This method is also handy on a shared or work Mac where you would rather not change files in Finder.

Which method should you use?

  • Quick Actions when you just need everything in one file, fast.
  • Preview when you need to drop specific pages, rearrange individual pages or check each page.
  • A browser tool when you want the same steps on every device, or Finder and Preview are giving you trouble.

Removing or adding pages after combining

Combined files often include pages you don’t need, such as blank backs of scanned sheets or terms-and-conditions pages from a statement. In Preview, select those thumbnails and press Delete. In a browser, Delete PDF Pages lets you click the pages to remove. To slot an extra page into the middle of a document, use Add Pages to PDF and choose the position.

Troubleshooting

  • “Create PDF” is missing from Quick Actions. Open System Settings, search for “Extensions”, and make sure Create PDF is enabled under Finder extensions.
  • The file is password-protected. Open it in Preview with the password, then use File → Export as PDF to save an unlocked copy you are allowed to edit.
  • The combined file is too large to email. Large scanned pages are usually the cause. Rescanning at a lower resolution, or rebuilding from compressed photos, makes the biggest difference.
  • Pages are in the wrong order. In Preview, drag thumbnails into place before exporting; with Quick Actions, rename the files with numbers and try again.
