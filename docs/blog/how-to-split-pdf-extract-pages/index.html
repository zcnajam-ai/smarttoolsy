How to Split a PDF and Extract Only the Pages You Need

Published 2026-10-24

You rarely need to send a whole PDF. An application might want only the signature page of a contract, your accountant might need one month from a year-long statement, or a 40 MB scan might be too large to email in one piece. Splitting a PDF lets you keep exactly the pages you need.

The fastest way: a browser tool

Use our Split PDF tool on any phone or computer:

  1. Choose your PDF. The tool shows how many pages it contains.
  2. Type the pages you want, for example 2, 5-7.
  3. Choose whether you want one combined file, one file per range, or one file per page.
  4. Click “Split PDF” and download the results.

The document is processed entirely in your browser and is not uploaded, which matters for financial and legal paperwork.

How to write page ranges

  • 3 takes a single page.
  • 4-9 takes pages 4 to 9, including both.
  • 12- takes page 12 through the last page.
  • 1, 3, 5 takes three separate pages.
  • 5, 1 puts page 5 before page 1, a quick way to reorder pages.

The built-in “print to PDF” trick

If you only need one continuous range, most devices can do it through the print dialog:

  1. Open the PDF in Chrome, Edge or your PDF viewer.
  2. Choose Print.
  3. Set the printer to “Save as PDF” (or “Microsoft Print to PDF” on Windows).
  4. Under Pages, enter the range you want, such as 3-5, and save.

This works well for simple cases. Two drawbacks: it can flatten fillable form fields, and some printers’ drivers re-render the pages, which may increase the file size or make text less sharp. The split tool copies pages exactly instead.

On a Mac

In Preview, show the thumbnail sidebar (View → Thumbnails), select the pages you want, and drag them onto the desktop. Preview creates a new PDF containing just those pages.

Common reasons to split a PDF

  • Sending only what is asked for. A landlord may need proof of income, not every page of your tax return. Sharing less personal data is safer.
  • Meeting upload limits. Splitting a long scan into two or three files can bring each one under a portal’s size limit.
  • Separating a batch scan. If you scanned a stack of receipts as one file, the “every page as its own PDF” option gives you one file per receipt.
  • Building a new document. Extract the pages you need from several files, then join them with Merge PDF.

Example: getting a large scan under an upload limit

Say a portal accepts files up to 5 MB and your scanned lease is a 12 MB, 18-page PDF. First check whether the portal allows several files. If it does:

  1. Open the lease in Split PDF and choose “Each range as a separate PDF”.
  2. Enter three ranges, such as 1-6, 7-12, 13-18.
  3. Check the size shown next to each download. Scanned pages are usually similar in size, so equal ranges give similar files. If one part is still too big, split that range again.
  4. Name the parts in order, such as Lease-part-1-of-3.pdf, so the reviewer reads them correctly.

If the portal accepts only one file, splitting will not help. In that case you need to reduce the size of the images inside the pages, for example by rescanning at 150–200 DPI instead of 600 DPI, or by photographing the pages and rebuilding the PDF from compressed images with JPG to PDF.

Keeping track of what you removed

When you send only part of a document, it can help to tell the recipient. A short note such as “Attached are pages 1–3 and the signature page, 12, of the agreement” avoids confusion and shows you did not leave anything out by accident. Keep the original full PDF in a safe place, because splitting creates new files and never changes the original.

Does splitting reduce quality?

No. A proper split copies each page as it is: text stays selectable, images keep their resolution and the page size does not change. If your split files are still large, the size comes from high-resolution images inside the pages; splitting can’t shrink those.

What about password-protected PDFs?

A PDF with an open password must be unlocked before any tool can read its pages. Open it in your PDF reader with the password and save an unprotected copy, provided you have the right to do so.
