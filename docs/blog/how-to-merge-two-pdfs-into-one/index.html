How to Merge 2 PDFs Into 1 (Free, in Under a Minute)

Published 2026-10-24

Combining two PDFs is one of the most common document chores: a résumé and a cover letter, a form and its signature page, two halves of a scan, or a statement and a receipt. It should take less than a minute. Here is the fastest way on each device, and how to make sure the pages end up in the right order.

The one-minute method (any device)

  1. Open Merge PDF in your browser.
  2. Tap “Choose PDF files” and select both PDFs.
  3. Check the order. The file at the top becomes the first pages. Use the arrow to swap them if needed.
  4. Tap “Merge PDFs”, then “Download merged PDF”.

That’s it. The two files are joined inside your browser, so nothing is uploaded, and every page keeps its original quality.

On Windows

Windows doesn’t include a feature that joins existing PDFs. The free Adobe Acrobat Reader app can view and sign PDFs, but combining files is part of Adobe’s paid Acrobat plans. A browser tool is the simplest free option: open Merge PDF in Edge or Chrome, select both files from File Explorer, and merge.

On a Mac

Select both files in Finder, Control-click and choose Quick Actions → Create PDF. Or open the first file in Preview, show thumbnails (View → Thumbnails), drag the second file into the sidebar below the last page, and choose File → Export as PDF. Our guide to combining PDFs on a Mac covers both methods in detail.

On iPhone or iPad

Save both PDFs to the Files app, tap the “…” button and choose Select, tap the two files, then tap “…” at the bottom and choose Create PDF. The new file appears in the same folder.

On Android

Most Android phones don’t include a built-in way to merge PDFs. Open Merge PDF in Chrome, choose the two files from Downloads or Google Drive, and merge them there.

Getting the order right

Most mistakes come from the order of the pages, not the merge itself. A few habits help:

  • Decide what the reader should see first. For applications, that is usually the cover letter or the form, followed by supporting documents.
  • Check the first and last page after merging. Scroll through the new PDF before you send it.
  • Need the second file in the middle of the first? Merging only joins files end to end. To insert pages after, say, page 3, use Add Pages to PDF and choose “After page 3”.

Merging two pages onto one sheet

Some people searching for this actually want two pages printed side by side on one sheet of paper. That is a printing setting rather than a merge: in your PDF viewer’s Print dialog, look for “Pages per sheet” or “Multiple” and choose 2. If you need it as a file, print to PDF with that setting.

Common questions

  • Will the merged file be bigger? It will be about the size of both files added together, since pages are copied as they are.
  • Can I merge a PDF with a photo? Yes. Convert the photo with JPG to PDF first, or use Add Pages to PDF, which accepts images directly.
  • What if one file is password-protected? Open it with the password and save an unlocked copy first. Merging tools cannot read locked files.
