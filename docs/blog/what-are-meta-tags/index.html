What Are Meta Tags? The Ones That Matter for SEO (With Examples)

Published 2026-10-25

Meta tags are snippets of HTML in the <head> section of a web page. Visitors never see them on the page, but search engines, browsers and social networks read them to understand the page and decide how to show it. A handful of them shape how your site appears in Google and how your links look when they’re shared. Most of the rest are optional or obsolete.

The meta tags that matter

1. Title tag

<title>Free Mortgage Calculator – Monthly Payment with Taxes</title>

Technically not a meta tag, but the most important tag in the head. It’s the blue headline in search results, the text in the browser tab, and a strong signal of what the page is about. Keep it unique for every page, around 50–60 characters, with the main topic near the start.

2. Meta description

<meta name="description" content="Work out your monthly mortgage payment with taxes, insurance and PMI. Free, no sign-up.">

The short summary under the title in search results. Google says it doesn’t use descriptions as a ranking factor, but a specific, useful description persuades more people to click. Aim for about 120–160 characters. Test yours in the SERP preview tool.

3. Viewport

<meta name="viewport" content="width=device-width, initial-scale=1">

Tells phones to fit the page to the screen. Without it, mobile visitors see a tiny desktop layout. Google indexes the mobile version of your pages, so this one is essential.

4. Robots

<meta name="robots" content="noindex, follow">

Only needed when you want to change the default. noindex keeps a page out of search results (useful for thank-you pages, internal search results and thin pages); nofollow asks search engines not to follow the page’s links. Pages without a robots tag are indexed and followed normally.

5. Canonical link

<link rel="canonical" href="https://example.com/mortgage-calculator/">

Points to the preferred URL when the same content is available at several addresses, such as with tracking parameters or both www and non-www. It helps search engines combine signals onto one page.

6. Charset

<meta charset="utf-8">

Tells the browser how to read the characters on the page, so symbols, accents and emoji display properly. Put it first in the head.

7. Open Graph tags

<meta property="og:title" content="Free Mortgage Calculator">
<meta property="og:description" content="Monthly payment with taxes, insurance and PMI.">
<meta property="og:image" content="https://example.com/share.jpg">

Control the preview card when a link is shared on Facebook, LinkedIn, WhatsApp, Slack and most messaging apps. They don’t affect Google rankings, but a good image and headline make shared links far more clickable.

8. X (Twitter) card

<meta name="twitter:card" content="summary_large_image">

Tells X to show a large image preview. X falls back to your Open Graph tags for the title, description and image.

Meta tags you can ignore

  • Meta keywords: Google has ignored it for well over a decade, and it hands your keyword list to competitors.
  • Revisit-after, rating, distribution, author and similar: not used by Google for ranking.
  • Language meta tags: declare the language with <html lang="en"> instead, and use hreflang links for translated versions.

How to add meta tags

  • Hand-coded sites: paste the tags inside <head>. The meta tag generator writes them for you with live previews.
  • WordPress: an SEO plugin such as Yoast SEO, Rank Math or All in One SEO adds title, description, canonical and Open Graph fields to every post.
  • Shopify, Wix and Squarespace: use the “SEO” or “Search engine listing” section in each page’s settings.

How to check a page’s meta tags

Right-click the page and choose “View page source”, then look between <head> and </head>. Or run the page through the SEO checker, which reads the title, description, robots, canonical, Open Graph and X tags and flags anything missing or too long.

Common questions

  • Do meta tags improve rankings? The title tag helps search engines understand the page. The description, Open Graph and X tags mainly improve clicks. Robots and canonical tags prevent problems rather than boost rankings.
  • Why doesn’t Google show my meta description? Google picks its own snippet when it thinks page text answers the search better. That’s normal; a good description is still used for many queries.
  • How many meta tags should a page have? There’s no target number. The eight above cover almost every site.
