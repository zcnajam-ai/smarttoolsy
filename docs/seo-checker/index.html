SEO Checker

Score any page on 40+ SEO checks, with clear fixes.

The SEO checker reviews a single web page the way a search engine sees it and gives it a score out of 100. It runs more than 40 checks across the page’s title and description, headings, content, links, images, social tags, structured data, crawling rules, security and speed, then tells you in plain English what passed, what needs attention and how to fix it.

It’s free with no daily limit and no account. Check your own pages as often as you like while you fix them, or look at a competitor’s page to see what they do differently.

How to use the SEO checker

  1. Enter the address of the page you want to check, such as example.com or a full link to a blog post.
  2. Click “Check SEO”. The report is usually ready in a few seconds.
  3. Start with the red Failed items, then the amber Warnings. Use the filter buttons to show only one type.
  4. Fix the issues on your site, then run the check again to see your score improve.

What the checker looks at

  • Title, description and keywords: whether the title and meta description exist, how long they are, and whether the words used most on the page also appear in them. A Google preview shows roughly how the page could look in search results.
  • Headings and content: one clear H1, subheadings, and how much readable text the page has.
  • Links and images: missing alt text, internal links and links with no text.
  • Social sharing and structured data: Open Graph and X (Twitter) card tags, schema.org markup and a favicon.
  • Crawling and indexing: the HTTP status, redirects, noindex tags, the canonical tag, robots.txt, the XML sitemap, how missing pages respond, URL format, the page language, and whether the www and non-www versions point to one place.
  • Security: HTTPS, the HTTP-to-HTTPS redirect, mixed content, HSTS, exposed server versions, plain-text email addresses and the domain’s SPF record.
  • Mobile and HTML code: the mobile viewport, doctype, character encoding and outdated HTML.
  • Speed: server response time, HTML size, compression, render-blocking scripts, the number of files and the size of the page structure. For a full speed audit, use the page speed test.

How the SEO score works

Each check has a weight based on how much it matters. Problems that can stop a page ranking at all, such as a noindex tag, a missing title or an error status, count the most. A pass earns full points, a warning half, and a failure none. The score is the share of available points the page earns.

Treat the score as a to-do list, not a grade. A page can score 100 and still not rank if the content doesn’t match what people are searching for, and a page with a few warnings can rank well if it’s the best answer. Useful, original content and links from other sites matter most.

What this tool can’t see

The checker reads the HTML your server sends. Content added later by JavaScript, pages behind a login, and sites that block automated visitors may show fewer details than a browser would. It also checks one page at a time, so run it on your most important pages individually. For data on which searches you already appear in, use Google Search Console.

Frequently asked questions

Is the SEO checker really free?

Yes. There’s no sign-up, no daily limit and no paid plan. Check as many pages as you like.

What happens to the address I enter?

Unlike our other tools, this one can’t run entirely in your browser, because browsers don’t allow one website to read another. The address is sent to our server, which downloads that public page, its robots.txt and sitemap, and sends the findings back to you. We don’t save your reports.

Why does my page fail the 404 check?

The checker requests a made-up address on your site. If it comes back as a normal page (status 200) instead of “not found” (404), search engines may treat empty pages as real ones. Ask your host or developer to return a proper 404 status for missing pages.

How long should a title and meta description be?

Aim for about 30–60 characters for the title and 70–160 for the description. Google measures width in pixels rather than characters, so these are guides rather than strict limits. Put the most important words first.

Can I check a competitor’s website?

Yes. Any public page works. Comparing your page with the one ranking above you is a quick way to spot missing headings, thin content or absent structured data.
