QR Code Generator

QR codes for links, text and Wi-Fi, downloadable as PNG.

Make a QR code for a website, a message, a phone number, an email address or your Wi-Fi network. The code updates as you type, and you can download it as a sharp PNG image for printing on menus, flyers, business cards or packaging. Codes made here are static: they contain the data directly, never expire and do not route through any tracking service.

How to use it

  1. Choose what the QR code is for.
  2. Fill in the link, text or Wi-Fi details.
  3. Pick a size and colors, then click “Download PNG”.
  4. Scan it with your phone camera to test before you print.

Tips for QR codes that scan every time

  • Keep strong contrast. A dark code on a light background works best. Some phone cameras cannot read light codes on dark backgrounds.
  • Print big enough. A common rule is that the code should be at least one tenth of the distance it will be scanned from. For a poster read from 2 metres, aim for 20 cm.
  • Leave a quiet zone. Keep a clear margin around the code free of text or graphics. The generator adds one automatically.
  • Shorter data, simpler code. Long URLs make dense codes that are harder to scan when printed small.

How Wi-Fi QR codes work

A Wi-Fi code stores the network name, password and security type in a standard format. When guests scan it, Android and iPhone cameras offer to join the network without typing the password.

Frequently asked questions

Do these QR codes expire?

No. The information is stored inside the image itself, so the code works for as long as the link or details inside it are valid.

Can I use them commercially?

Yes. QR codes you create here are free to use on anything, including printed products and packaging.

Can I change the link after printing?

No, static codes cannot be edited. If you need to change the destination later, point the code to a page on your own website that you can update or redirect.
