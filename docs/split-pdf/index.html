Split PDF

Extract pages or split one PDF into several files.

Output

    Split PDF lets you pull out just the pages you need from a larger document, or break one PDF into several smaller files. Send only the signed page of a contract, separate a scanned bundle into individual receipts, or cut a long report into chapters.

    How to split a PDF

    1. Choose a PDF. The tool shows how many pages it has.
    2. Type the pages you want, using commas and dashes, such as 1-3, 5, 8-10. Leave the box empty to use every page.
    3. Pick an output: one combined file, one file per range, or one file per page.
    4. Click “Split PDF” and download the files from the list.

    Writing page ranges

    • 4 takes only page 4.
    • 2-6 takes pages 2 to 6, inclusive.
    • 10- takes page 10 to the end.
    • 1, 3, 5 takes three separate pages. In “separate PDF” mode each becomes its own file.

    Pages keep their original quality, text and size. Nothing is re-compressed.

    Frequently asked questions

    Are my files uploaded to a server?

    No. The files are opened and processed by JavaScript in your own browser. Nothing is sent to SmartToolsy or anyone else, which makes the tool safe for contracts, bank statements and other private documents.

    Can I reorder pages while splitting?

    Yes. Pages are taken in the order you type them, so 3, 1, 2 produces a file that starts with page 3.

    Why can’t I open my file?

    Password-protected PDFs must be unlocked first. Damaged files may also fail; try opening and re-saving the PDF in your reader.
