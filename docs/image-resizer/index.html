Image Resizer

Exact pixels, percent or a target size in KB.

Download resized image

The image resizer changes the dimensions of a photo or graphic in a couple of clicks. Set an exact width and height in pixels, scale by a percentage, or enter a maximum file size, such as 100 KB, and the tool finds the best quality that fits. It works with JPG, PNG and WebP, and your images are resized on your own device, never uploaded.

How to resize an image

  1. Choose an image. Its current size appears in the width and height boxes.
  2. Type a new width; the height follows automatically while “Keep proportions” is ticked. Or switch to Percentage.
  3. Optionally choose a format and a maximum file size in KB.
  4. Click Resize, check the preview and size, then download.

Resizing to a specific file size

Many application forms and websites limit uploads to a size such as 50 KB, 100 KB or 2 MB. Enter the limit in “Max file size” and the tool lowers the JPG or WebP quality step by step until the file fits. If it still can’t, reduce the width and height too; fewer pixels always means a smaller file. PNG files are lossless, so a size limit only works by shrinking dimensions; switch to JPG for photos.

Will resizing reduce quality?

Making an image smaller keeps it sharp. The tool scales down in steps for smooth, clean results. Making an image larger can’t add detail that isn’t there, so enlarged photos look softer; for print, start from the largest original you have.

Need a particular shape, not just a size? Use the image cropper first. To make files smaller without changing dimensions, try the image compressor.

Frequently asked questions

What does “keep proportions” do?

It locks the aspect ratio, so changing the width updates the height automatically and the picture isn’t stretched or squashed.

What size is a 2 × 2 inch photo in pixels?

At 300 pixels per inch it’s 600 × 600 pixels. Check the exact requirements of the office or website you’re submitting to, as rules on background, head size and file size vary.

Are my images uploaded?

No. Everything happens in your browser using the canvas feature built into every modern browser.
