Case Converter

Switch text between UPPER, lower, Title, Sentence, camelCase and more.

The case converter changes the capitalization of any text in one click. Fix a paragraph someone typed with Caps Lock on, turn a list of names into proper Title Case, or format variable names for code. The result replaces the text in the box so you can convert again or copy it straight away.

How to use it

  1. Paste or type your text into the box.
  2. Click the case you want. The text changes immediately.
  3. Click “Copy result” and paste it wherever you need it.

What each option does

  • UPPERCASE makes every letter a capital. Good for headings and labels.
  • lowercase makes every letter small. Useful for cleaning up email lists or tags.
  • Title Case capitalizes the main words and keeps short words like “a”, “of” and “the” in lowercase unless they start the title, following common headline style.
  • Sentence case capitalizes the first letter of each sentence and lowercases the rest. This is the style most modern websites use for headings and buttons.
  • camelCase and PascalCase remove spaces and capitalize each word, used for JavaScript and Java names.
  • snake_case joins words with underscores, common in Python and databases.
  • kebab-case joins words with hyphens, used in URLs and CSS class names.

Frequently asked questions

Will Sentence case fix names and places?

No tool can know every proper noun, so names like “London” or “Sara” will become lowercase in the middle of a sentence. Read through the result and capitalize names by hand.

Can I convert a whole document?

Yes. There is no length limit beyond what your browser can handle comfortably, which is many thousands of words.

Does it keep line breaks?

For UPPER, lower, Title and Sentence case, yes. The code-style options (camelCase, snake_case and so on) convert each line separately so a list of names becomes a list of identifiers.
